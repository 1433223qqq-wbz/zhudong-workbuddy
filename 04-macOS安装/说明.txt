诛冬破甲 · WorkBuddy 版 v1.5.0 · macOS 安装说明
=====================================================
适用：macOS（Intel / Apple Silicon 都行）+ WorkBuddy 5.x
数据目录：~/.workbuddy（Finder 里 ⌘⇧G 输入 ~/.workbuddy 可打开）

诛冬群：QQ群 994974110
加群链接：https://qm.qq.com/q/IR15E9xWkS
入群暗号：诛冬

=====================================================
【1】装之前

  1.1  WorkBuddy 至少启动过一次，~/.workbuddy 已生成。
  1.2  完全退出 WorkBuddy：⌘Q，确认 Dock 与菜单栏图标都没了。
  1.3  准备 python3（macOS 自带，或终端跑 xcode-select --install）；hook 注入要用它。

=====================================================
【2】安装

  2.1  解压整个压缩包到任意目录，比如 ~/Downloads/诛冬破甲-WorkBuddy版

  2.2  终端执行（路径换成你自己的）：

       chmod +x ~/Downloads/诛冬破甲-WorkBuddy版/04-macOS安装/install-mac.command
       bash ~/Downloads/诛冬破甲-WorkBuddy版/04-macOS安装/install-mac.command

  2.3  看到下面这些就算成功：

       ==> [1/7] 安装包自检通过（payload 4 个 + hook 4 个）
       ==> [2/7] 目标人格目录 N 个：
       ==> [3/7] 人格已写入 N 个文件（备份 N 个）
       ==> [4/7] hook 已注入 2 处配置（SessionStart + UserPromptSubmit）
       ==> [5/7] BOOTSTRAP.md 已清除 N 个
       ==> [6/7] 加群信息已写入 加群.txt
       ==> [7/7] 完成
       ==== 诛冬破甲 · WorkBuddy 版 v1.5.0 安装完成 ====

  2.4  跑完会自动打开加群页面与包内推广页 05-推广页/index.html。
       不想自动打开：ZHUODONG_NO_OPEN_GROUP=1 ZHUODONG_NO_OPEN_PAGE=1 bash install-mac.command

  2.5  ⌘Q 退出 WorkBuddy，再重新打开，开个新会话。

=====================================================
【3】验证

  3.1  它自称「诛冬」
  3.2  它叫你「老大」
  3.3  每轮回答最后一行：诛冬群 QQ群：994974110
  3.4  文件层面：ls -l ~/.workbuddy/zhudong  应看到 kernel.md / reminder.md / hook.sh
       cat ~/.workbuddy/settings.json | grep -c zhudong  应 >= 2

=====================================================
【4】卸载

      bash ~/Downloads/诛冬破甲-WorkBuddy版/04-macOS安装/uninstall-mac.command

  会还原人格文件、删 .zhudong-armor.json 与 zhudong 目录、摘掉两条 hook。卸完 ⌘Q 再打开。

=====================================================
【5】常见问题

  Permission denied                没 chmod +x，按 2.2 第一行再来一次
  没有 python3                     xcode-select --install；装完重跑，hook 才会注入
  人格没变化                       没 ⌘Q 完全退出；旧会话缓存；重跑 2.2
  最后一行没有群号                 hooks 没进 settings.json：cat ~/.workbuddy/settings.json 搜 zhudong
  BOOTSTRAP.md 又出现              没重启就开会话；重启后重跑安装
