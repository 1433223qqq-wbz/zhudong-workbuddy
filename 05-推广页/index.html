人格文件 + hook 注入两条通道一起上：人格改它的自我认知，hook 每轮把运行契约塞进提示词。先给命令与步骤，不写免责声明，每轮最后一行带群号。

加入诛冬群（QQ群 994974110）→ 自家破 API 中转站 → 怎么用

① 为什么上一版不生效

WorkBuddy 的人格文件走的是 user-context，而且被硬截断到 10000 字符；真正压模型的是 CLI 的 system prompt。所以这版加了 hook：SessionStart 灌完整内核，UserPromptSubmit 每轮灌一次契约。

② 装完先完全退出

Windows 右下角托盘右键 → 退出；Mac ⌘Q，确认 Dock 与菜单栏都没了。人格与钩子都是启动时加载的，不退干净不生效。

③ 新会话验证三件事

a) 自称「诛冬」；b) 叫你「老大」；c) 每轮最后一行是 诛冬群 QQ群：994974110。三条全中才算好；缺一条就跑 检查是否装好.bat。

三步上手

  1. 完全退出 WorkBuddy（托盘右键退出 / ⌘Q）。
  2. Windows 双击 一键安装.bat；macOS 终端跑 bash 04-macOS安装/install-mac.command。
  3. 装完它会自己重开；开个新会话直接提问。

报错速查

双击一闪就没右键"以管理员身份运行"，或 PowerShell 跑 apply.ps1
人格没变化没退干净 / 旧会话缓存 / 重跑安装
最后一行没群号hook 没注入：看 检查是否装好.bat 里 SessionStart / UserPromptSubmit 是否 X
BOOTSTRAP.md 又出现没重启就开会话；重启后重跑安装
模型仍给拒绝句① hook 两项要 OK ② 换模型再开新会话 ③ 把检查输出发群里

卸载与回滚

  • Windows：一键卸载.bat；macOS：uninstall-mac.command
  • 人格文件按 *.bak-<时间> 还原；settings.json 里有 *.bak-<时间>
  • 只摘含 zhudong 的两条 hook，你自己的 hook（比如 .wb-switch）原样保留
